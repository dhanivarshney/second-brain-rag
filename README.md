# 🧠 SECOND BRAIN: AI-Powered Skill Intelligence & Personalized Learning Platform
### Smart India Hackathon 2026 · Problem Statement SIH26101
**Domain:** Ministry of Statistics and Programme Implementation (MoSPI) / India's Official Statistical System  
**Integration:** iGOT Karmayogi Ecosystem (API-Ready Capacity Building Architecture)

---

## 📌 Problem Statement Overview (SIH26101)
> **"Develop an AI-enabled learning platform that identifies competency gaps, recommends personalized training through integration with the iGOT Karmayogi ecosystem, and is capable of generating Quizzes and Multiple Choice Questions (MCQs) from uploaded learning materials to strengthen capacity building in India's Official Statistical System."**

Second Brain transforms institutional learning materials (survey manuals, National Accounts guidelines, NSS frameworks, price indices, data governance acts) into an active, competency-driven learning companion. It bridges the gap between static government training materials and continuous capacity building for statistical cadres across India.

## 🏛 4 Core Competency Domains & Taxonomy

Second Brain implements a structured competency taxonomy specifically calibrated for the National Statistical System:

1. **📊 Statistical Competencies**
   - Survey Design & Sampling (NSS multistage designs, FSUs, stratification, sample size)
   - Descriptive & Inferential Statistics (Distributions, hypothesis testing, regression)
   - National Accounts & GVA (SNA principles, Gross Value Added compilation, constant deflators)
   - Price Statistics & Indices (CPI, WPI, IIP, Laspeyres, Paasche, Fisher formulas)
   - SDG Indicators & Data Quality (National Indicator Framework - NIF, SDMX standards)

2. **💻 Technical Competencies**
   - Python for Statistical Analysis (Pandas, NumPy, data cleaning, automated pipelines)
   - R Programming & Econometrics (Survey packages, econometric modelling)
   - SQL & Relational Database Systems (Large-scale microdata extraction, aggregation)
   - Data Visualization & BI (Executive indicator dashboards, visual storytelling)
   - AI/ML in Official Statistics (Supervised classification, NLP for survey texts, anomaly audits)

3. **🛡️ Digital Governance**
   - Cybersecurity & Data Privacy (Statistical microdata anonymization, DPDP Act compliance)
   - Digital Public Infrastructure & Cloud (MeghRaj cloud, API-based interoperability, data.gov.in)

4. **🤝 Behavioural & Managerial**
   - Statistical Ethics & Integrity (UN Fundamental Principles of Official Statistics, respondent confidentiality)
   - Project Management & Communication (Field enumerator cohort management, survey scheduling)

## 📈 Transparent Adaptive Competency Scoring Formula

Second Brain avoids artificial jumping or opaque score mutations. When a learner completes a diagnostic test or practice quiz:

$$\text{New Score} = \text{round}\left(\text{Old Score} \times 0.60 + \text{Assessment Score} \times 0.40\right)$$

- **60% Weight:** Historical demonstrated competency (prevents volatility).
- **40% Weight:** Newly demonstrated performance.
- Both `score` and `previous_score` are recorded in SQLite, generating transparent **Before (e.g. 45%) $\rightarrow$ After (e.g. 67%)** progression banners across the platform.

## 🛠 Tech Stack & Architecture

| Component | Technology | Description |
|---|---|---|
| **Frontend** | Streamlit + Custom CSS | Responsive dark glassmorphism workspace with role switcher |
| **LLM Inference** | Groq API (`openai/gpt-oss-120b`) | Evidence-grounded generation, diagnostic evaluation, strict JSON |
| **Retrieval Engine** | Local Hybrid Search | 384-dim Blake2b hash embeddings + BM25/keyword phrase scoring |
| **Document Parsing** | PyMuPDF + pytesseract OCR | PDF, DOCX, TXT parsing with automatic image OCR fallback |
| **Persistence** | SQLite (`users.db`) | Local database for profiles, competencies, assessments, memories, quiz logs |
| **Security / Auth** | SQLite + `bcrypt` | Secure local credentials; documents never leave the host machine |

## ⚡ Quick Start & Installation

### Prerequisites
- Python 3.10+
- [Tesseract OCR](https://github.com/UB-Mannheim/tesseract/wiki) (for scanned PDFs)
- [Groq API Key](https://console.groq.com)

### Setup Instructions

```powershell
# 1. Open project directory
cd c:\Users\hp\second-brain-rag

# 2. Activate Python virtual environment
.\.venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Configure .env file in project root
# GROQ_API_KEY=gsk_your_groq_api_key_here

# 5. Launch the Second Brain platform
.\.venv\Scripts\streamlit.exe run app.py
```

Open **http://localhost:8501** in your browser.

## 🔒 Privacy & Grounding Guarantees
- **Strict Evidence Grounding**: The Q&A and quiz generator explicitly cite document filenames and page numbers, preventing hallucinations.
- **Local-First Data Protection**: Sensitive government statistical notes and learner evaluation records stay stored in local SQLite (`users.db`).
